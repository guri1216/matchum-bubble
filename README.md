# 맞춤법 말풍선 (안드로이드)

카톡·문자 등에서 글을 쓰면 입력창 위에 `되요 → 돼요` 같은 말풍선이 뜨고, 누르면 바로 고쳐지는 앱입니다.
지금 쓰는 키보드는 그대로 사용합니다.

## 폰에 설치하는 방법 (처음이어도 OK)

1. **Android Studio 설치** — https://developer.android.com/studio 에서 받아 설치 (설치 중 나오는 기본 옵션 그대로 Next)
2. **프로젝트 열기** — 이 압축을 풀고 Android Studio에서 `Open` → `MatchumBubble` 폴더 선택
   - 처음 열면 필요한 파일을 내려받느라 몇 분 걸려요 (아래 진행 막대가 끝날 때까지 기다리기)
   - "Upgrade" 제안이 뜨면 일단 닫아도 됩니다
3. **폰 준비** — 폰 `설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호`를 7번 톡톡 → 개발자 모드 켜짐
   → `설정 > 개발자 옵션 > USB 디버깅` 켜기 → USB 케이블로 컴퓨터에 연결 → 폰에 뜨는 "허용" 누르기
4. **실행** — Android Studio 위쪽에 내 폰 이름이 보이면 초록색 ▶ 버튼 클릭 → 폰에 앱이 설치되고 열림
5. **켜기** — 앱을 열면 안내창이 떠요. `확인` → 바로 열리는 화면에서 `맞춤법 말풍선` 스위치 켜기 → `허용` (처음 한 번만)
   - "제한된 설정"이라고 막히면: `설정 > 애플리케이션 > 맞춤법 말풍선 > ⋮ > 제한된 설정 허용` 후 다시

## AI 검사 (선택)
앱에서 `AI 검사 버튼 사용`을 켜고 Anthropic API 키(https://console.anthropic.com)를 넣으면 말풍선에 ✨AI 버튼이 생깁니다.
버튼을 누를 때만 그 문장이 전송되고, 띄어쓰기·문맥까지 고쳐 줍니다.

## 파일 구조
- `RuleChecker.kt` — 폰 안에서 도는 맞춤법 규칙 (여기에 규칙을 한 줄씩 추가 가능)
- `SpellService.kt` — 입력창을 보고 말풍선을 띄우는 부분
- `AiChecker.kt` — Claude API 호출
- `MainActivity.kt` — 설정 화면
